How to Use This Reference

Navigate using the sidebar. Use the search bar to find specific architectures or concepts instantly across all sections.

📐 Architecture Design: Data and logic are strictly separated. All content lives in the DATA LAYER JavaScript objects. The rendering layer reads from data and builds the UI. Language toggle swaps between en/vi keys. Theme toggle switches CSS variables.
📊 SPAMF Legend: Security · Performance · Availability · Maintainability · Flexibility — the five pillars used to evaluate every architecture.
⚡ Architecture Decision Guide: Start with Monolith unless you have a clear reason not to. Add Layered structure immediately for maintainability. Graduate to Microservices only when scaling and team boundaries demand it. Apply DDD + Hexagonal in complex domains. Use CQRS + Event Sourcing only when query/write disparity is extreme.
